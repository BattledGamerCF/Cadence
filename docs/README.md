# Documentation

- [ARCHITECTURE.md](ARCHITECTURE.md): a map of the source tree. It covers the four mods, what each package holds and where to start.
- [FOR-REVIEWERS.md](FOR-REVIEWERS.md): for mod-platform reviewers. It covers native code, network (no connections of its own), files written and licences.
- [COVERAGE.md](COVERAGE.md): every part of Minecraft that runs during play, and what Cadence does there.
- [API.md](API.md): the API for addon mods (drawing on Metal, what OpenGL calls can't do), and the Iris API that Cadence answers.
- [SHADER-PACKS.md](SHADER-PACKS.md): which shader packs work, what was fixed for them, and known issues.
- [GAME-LOGIC.md](GAME-LOGIC.md): Cadence Logic, the game-logic optimizations that replace Lithium.
- [COMPATIBILITY.md](COMPATIBILITY.md): other mods tested with Cadence, and how the compatibility layers work.
- [CHANGES-FROM-MCOPT.md](CHANGES-FROM-MCOPT.md): what Cadence changed or added compared with mcopt.
- [BENCHMARKS.md](BENCHMARKS.md): measured fps, shader packs, far terrain on a small GPU, and the whole Mac's power draw.
- [IDEAS.md](IDEAS.md): the idea queue. It lists what was proposed, built or dropped, and why.
- [MINIMAL-RENDERER.md](MINIMAL-RENDERER.md): the Minimal Renderer (Cadence's FPS-record renderer). It covers what it draws, the results and a record attempt.
