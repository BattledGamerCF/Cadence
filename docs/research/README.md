of visual glitches, and performance ideas. Much of it is reasoning rather than sourced fact, so check anything important
against the linked sources or a measurement first.

- [MSERIES.md](MSERIES.md): Apple Silicon chips M1-M6 (cores, bandwidth, cooling, detection).
- [SHADERPACKS.md](SHADERPACKS.md): how OptiFine/Iris shader packs work.
- [GLITCHES.md](GLITCHES.md): causes of motion glitches with shader packs.
- [PERF2.md](PERF2.md), [ROUND2.md](ROUND2.md), [ROUND3.md](ROUND3.md): performance ideas, round by round.
- [LITHIUM.md](LITHIUM.md): what Lithium does (for the clean-room Cadence Logic).
- [NIGHT5.md](NIGHT5.md): macOS edge cases (displays, power, Rosetta), chip features, memory on 8 GB Macs, settings UI conventions.
