# 10-19: the queue, an optimization pass, a bug pass, a Sonnet review, beta.7

The Wayfarer 12-hour chunk 30 had the Mac, so with the user's OK it was paused (wayfarer-runs/PAUSE) for the in-game
work: 06:46-07:12, 07:29-07:31, 07:32-07:34 (30 min in all), PAUSE removed by each script's exit trap.

## The queue (scratchpad queue3/queue4)
- **Native lookup broke the resource reload** (first native run): `getVertexFormatBindings()` has null slots (NPE in fits ->
  "Caught error loading resourcepacks", game stuck loading), and nothing matched anyway: the frontend's CreateInfo carries
  only the attributes and uniforms the compiled shaders use (SPIR-V reflection), not the pipeline's declared ones. Now
  NativePipelineSourceMixin records the RenderPipeline each CreateInfo is made from (PipelineBuilder.generateBackendCreateInfo
  RETURN); fallback: state + vertex buffers equal, uniforms a subset, fewest extras; any exception = translated.
- Rerun: **193 pipelines native, 0 failures**, plain and Fabulous (every OIT phase incl. composite and depth-bounds cull);
  pictures alike (differences only where things move); fps the same to a few % up (single runs).
- Particle writer A/B: render thread 0.786 vs 0.783 ms: nothing (the JIT had already removed vanilla's objects) -> removed;
  GPU particles not worth building either (the whole render thread is under 0.8 ms in that scene).
- Byte checks: model writer 83.6M faces, item quads 1.2M, 0 mismatches. Sweep (dynamic lights, screens, spectate,
  leave/rejoin, BSL, Complementary, Photon, off) passed (the pack part rerun alone after a memory-guard stop).

## Optimization (busy2.jfr vs busy1.jfr, crowded scene, render thread)
Entity models 29.6 -> 25.1% (Cube.compile 22.3 -> 16.3%; the sprite path gone). New: ModelQuadWriteMixin (items' baked
quads a quad at once; the item loop was ~10%). Native programs compiled once (one library, both stages). Left: particle cull
5.8% (memory-bound: the particle's first touch), matrix ops 6% (vanilla's math), the staging memcpy 5.4%.

## Bug pass, then the Sonnet 5.5 review (medium effort, read-only, no subagents)
Own pass: the native lookup (above), a pipeline leak on a failed translated retry. Sonnet: no crash/wrong-output/leak it could
substantiate; minor: a failed native source was retried at every reload (now remembered), the retry skipped the dump/override
hooks (fixed), a comment. Its "OIT alpha-only phases may lack the Fog slot" didn't happen: the in-game run compiled every
oit_depth_bounds_* / oit_transmittance_* pipeline native.

Open: one item_cutout compile still falls to the fallback matcher and is translated (safe).
