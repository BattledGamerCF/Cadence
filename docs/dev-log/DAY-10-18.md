# Day 2026-10-18: easier shaders, 13 more packs, a GPU pass

Asked for, in order: make shaders (and every menu) easier and less confusing after an audit; download and test more
shader packs for compatibility; then a GPU optimization pass for shader packs. M2 MacBook Air, the user's GUI scale 4,
short runs (the Mac was in use; the memory guard stopped one run for swap growth from other apps).

## 1. Menu audit

Walked every screen a player touches to use shaders, at GUI scale 4, with BSL on (self-test UI tour: Video Settings,
tooltips, Shader Pack Settings, Quick Setup). What was confusing:

| Before | Why it confused | Now |
|---|---|---|
| "Shader Pack: X" cycled one pack per click, applied when Video Settings closed | pack 10 of 12 took 10 clicks; nothing happened until you left; no way to see what's installed | **Shader Packs screen**: the whole folder as a list, click one to turn it on (O in game opens it) |
| A pack that failed said so once in chat | gone when the chat scrolled; the button still showed the pack | the list shows "Couldn't load: reason" under it for the session |
| No hint which packs work with Cadence | 23 tested packs, nothing in the game said so | "Tested with Cadence · Light/Medium/Heavy · note" or "Not tested with Cadence yet" (PackCatalog) |
| Separate Live, Quality and Folder buttons | three buttons for one decision; "Live" meant nothing to a player | gone: switching is always live when it can be, "restart to turn on" otherwise; Profile and Open Packs Folder in the list's footer |
| Shader options below the performance ones | the thing most players came for was at the bottom | Shaders and Shader Pack Settings first, then Performance and Quick Setup, then two labelled Cadence groups |
| "Pack Speed-ups: Built In / Check Now / On (checked) / Can't Tell" | didn't say what it speeds up (skipping shadow work), and long at GUI 4 | **"Faster Shadows: On / Test / Testing / Not Safe / Unsure / No Pack / No World"** |
| Pack Settings: change, Done, reopen to try again | no way to see an option's effect while choosing | **Apply** on every page; Reset at the top; one hint line (click: next, Shift-click: previous) |
| Graphics API option clickable | choosing OpenGL/Vulkan did nothing under Cadence | greyed, reads "Graphics API: Metal" |
| Status lines: "Cadence: automatic tuning ...", "Auto: world drawn at N% to keep it smooth", a raw compatibility list | several long lines, one per thing tuned | "Tuned automatically: resolution · cooling · background fps", heat and memory when relevant, "Works alongside: mods" |
| No keys | Iris users expect O and K | **O** opens Shader Packs, **K** toggles shaders off and back to the last pack (Controls > Miscellaneous; no Fabric API needed: mixins on Options.load and Minecraft.handleKeybinds) |
| Adding a pack: find the folder | Finder trip | drop .zip files (or folders with `shaders/`) on the list; the first one turns on; a zip that isn't a pack is refused with a message |
| No packs installed | an empty button | the list says how to add one; the button reads "Add Packs..." |

Checked in game (self-test steps `screen=packs`, `packpick=NAME`, `drop=PATH`, `key=NAME:press`): switching from the
list, K off and on, O with the in-use pack highlighted, dropping a non-pack zip, Apply in Pack Settings, the greyed
Graphics API row, and the empty state in a production launch with no packs.

## 2. Thirteen more packs

Details, per-pack fixes and GPU times: ../SHADER-PACKS.md (10-18 section). Summary: 11 of 13 work (Noble with shaded
sides darker than intended), so 23 of the 25 tested packs. Shrimple and Rethinking Voxels need geometry/tessellation
shaders; the list says so in plain words.

Bugs worth remembering:
- `sampler3D` goes through set 1 (storage) in Cadence's Metal layout, so 3D textures were never bound: Photon's sky
  read black (then sepia with the wrong filtering). `storageHandle()` now resolves a pack volume by program and sampler.
- `gcolor` is the block atlas in world programs (OptiFine): Nostalgia and Vanilla Plus drew every block as a flat colour.
- Metal's float3 in threadgroup memory is 16 bytes: Photon's 27 KB of shared vec3 became 36 KB, over Apple's 32 KB.
- Mellow names a varying `Normal` and an output `Color`, the adapter's vertex input names.
- Census false blockers: `textureLod`/`textureGather` on shadow samplers are fine with hardware comparison.

## 3. GPU pass

Kept: feedback copies only for samplers a program's code reads (Complementary Reimagined 44 -> 41 ms at 2940x1686, two
in-run A/Bs; 12 copies a frame to 2; BSL and Photon unchanged; pictures alike). Dropped with numbers: learned pass-clear
flushing (slower), relaxed shadow vertex math (noise), the read analysis for per-frame decisions (broke AstraLex, no gain).
Details in ../SHADER-PACKS.md.

Measurement notes:
- The fanless Air slows after ~2 minutes of full GPU load: Vanilla Plus read 31 ms late in a sweep and 12.4 ms in a short
  one. Sweep anchors (BSL, VanillaEX, Bliss) only help at the start; for a cost table, keep runs under 2 minutes or
  interleave an anchor.
- Self-test lines report the 10 s before the step's end: after `PACK,wait=12` the `wait` line is the pack's steady state.
- Auto resolution hides cost (every pack lands near 60 fps); use `-Dcadence.shaders.renderScale=0.5` for comparisons.
