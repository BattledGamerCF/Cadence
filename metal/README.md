# Cadence (metal)

The core mod (`cadence`): Minecraft's renderer replaced by native Apple Metal. Java code is in `src/main/java/dev/cadence/metal`,
the Objective-C side in `src/main/native` (built into `libmcmetal.dylib`), Metal shaders and profiles in
`src/main/resources/cadence`. Derived from [mcopt](https://github.com/noahdunnagan/mcopt) (Apache-2.0).
